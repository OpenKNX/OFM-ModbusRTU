**OFM-ModbusRTU**

OFM-ModbusRTU is a module for OpenKNX that facilitates communication with Modbus RTU devices, offering a straightforward method to integrate Modbus RTU-capable devices into the OpenKNX system.

**Features**
- **Integration of Modbus RTU Devices**: Enables seamless control and monitoring of Modbus RTU devices within the OpenKNX ecosystem.
- **Configuration**: Supports setup and management of up to 10 Modbus RTU slaves.

**Supported Modbus RTU Commands**
- `0x01` Read Coils
- `0x02` Read Contacts
- `0x03` Read Holding Registers (16-bit)
- `0x04` Read Input Registers (16-bit)
- `0x05` Write Single Coil
- `0x06` Write Single Register (16-bit)
- `0x10` Write Multiple Registers (16-bit)
